A little help with the punctuation

"..." marks literal text—a string. name without quotes means “use the value stored under this variable name”.

= means assignment: work out the right-hand side, then store the result under the name on the left.

+ joins these strings. This is called concatenation. Notice the space after the comma inside the welcome text.

input(...) asks for a response; print(...) displays a value. The brackets hold what we pass to each function.

Using VS Code, PyCharm or Colab

Use a Python 3 file in VS Code or PyCharm, or put all three lines in one Colab code cell. Run the whole example. When the prompt appears, enter your answer and press Enter.

No extra libraries are needed. Copy the quotes, brackets and variable names carefully. The computer needs precise instructions.

For the teacher · how this fits T1

The overview introduces the breadth of your T1 resources; the practical activity deliberately uses only input, variables, assignment, strings, concatenation and output. Constants, numeric data types, arithmetic, casting and further string handling are signposted rather than taught through extra tasks.

Ask for a prediction before each step. At line 2, emphasise that creating the message does not display it. At line 3, distinguish the variable name from the value it contains.

Keep the same school-club context as later topics introduce selection (T2), iteration (T3), arrays (T4), subprograms (T5), files (T6) and SQL (T7).
