Build on procedures & functions
def make_record(name, mark):
    return name + "," + str(mark) + "\n"

line = make_record("Jo", 65)

What are the parameters? What arguments are supplied? Is the returned value already saved to a file?

Reveal the connection

name and mark are parameters; "Jo" and 65 are arguments. The returned string is "Jo,65\n". It is in memory until code writes it to a file.

Two different saves: saving your .py source in the IDE is different from the running program writing data to a .txt file.

One row = one record

Select a record

A record groups related fields about one item or person. Here each record has a name and a mark.

Illustrative classroom data, not real pupil records.

A text file stores characters. A mark such as 65 must be converted from text before numeric comparisons.

Split into fields

fields = line.strip().split(",")
name = fields[0]
mark = int(fields[1])

strip() removes surrounding whitespace, including the newline. split(",") separates these simple fields.

This simple format assumes names contain no commas. General CSV can contain quoted commas and needs a proper CSV parser. The extension .txt does not stop a file holding comma-separated data.

Another useful Python pattern: automatic close
with open("marks_practice.txt", "r", encoding="utf-8") as file:
    text = file.read()
# The file is closed when the with block ends.
Exercises use explicit close() to make the lifecycle visible. with closes automatically, including when an exception leaves the block. There is no Python newFile() built-in: that is OCR reference-language notation.

Where will Python save my file?
from pathlib import Path
print(Path.cwd())
A relative filename is resolved from the current working directory, which is not always the script’s folder. Use your IDE’s project/run settings to choose a writable practice folder.
